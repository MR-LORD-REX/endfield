Endfield Client API Reference

Welcome to the Endfield SDK Documentation. This page provides a detailed reference for all publicly available methods on the Endfield client and the data models they return.

Methods

__init__(session=None, debug=False, timeout=5, proxy_pool=None)

Initialize the Endfield client.

Parameters

  • session (Optional[aiohttp.ClientSession]): Optional aiohttp.ClientSession to use for requests.
  • debug (bool): Enable debug logging. Default is False.
  • timeout (int): Timeout in seconds for requests. Default is 5.
  • proxy_pool (Optional[ProxyPool]): Optional ProxyPool to use for auth requests.

close() -> None

Close the internal aiohttp client session if it was not provided externally.

async get_factory_blueprints(region="Both", item="all", start=0, end=10) -> FactoryPlans

Gets factory blueprints from the Endfieldtools API, with optional filtering by region and output item, and pagination support.

Parameters

  • region (Literal["Americas/Europe", "Asia", "Both"]): Filter blueprints by region. Default is "Both".
  • item (Literal["all"] | items): Filter blueprints by output item. Default is "all".
  • start (int): The starting index for pagination (0-based). Default is 0.
  • end (int): The ending index for pagination (exclusive). Default is 10.

Returns

  • FactoryPlans: An object containing a list of blueprints and the total count of blueprints matching the filters.

Models

ShowcaseData

The master object representing a player's showcase data.

Attributes

  • profile (PlayerProfile): The basic player profile and statistics.
  • characters (List[CharacterData]): The list of characters in the player's showcase.
  • ttl (int | null): Time-to-live for cache.

PlayerProfile

Information regarding a player's profile in the game.

Attributes

  • uid (str): The player UID.
  • name (str): The player's name.
  • short_id (str): Short identifier.
  • signature (str): Player's signature.
  • avatar_url (str): Avatar image URL.
  • bg_url (str): Profile background URL.
  • adventure_level (int): The adventure level of the player.
  • world_level (int): The world level of the player.
  • char_count, weapon_count, doc_count (int): Statistics.
  • domain_progress (List[DomainProgress]): Progress across various domains.
  • medals (Medals): Player's achievements/medals.
  • characters (List[ProfileCharacter]): The characters configured in the player's profile display.

DomainProgress

Attributes

  • domain_id (str): Unique domain identifier.
  • level (int): Current progress level.
  • name (str): Display name of the domain.

Medals

Attributes

  • medals (List[Medal]): Collection of medals.

Medal

Attributes

  • index (int): Display index/order.
  • name (str): Name of the medal.
  • description (str): Achievement description.
  • icon_url (str): Medal image URL.

ProfileCharacter

Lightweight character data displayed on the user's profile card.

Attributes

  • template_id (int): Character template ID.
  • str_id (str): String identifier (e.g., "chr_0030_zhuangfy").
  • name (str): Character name.
  • level (int): Character level.
  • potential_level (int): Character potential level.
  • rarity (int): Character rarity (e.g., 6).
  • element (str): Elemental affinity.
  • profession (str): Class or profession (e.g., "ASSAULT").
  • splash_url (str): Character splash art URL.
  • round_icon_url (str): Round avatar icon URL.

CharacterData

Extensive data describing a character's stats, level, equipment, and talents.

Attributes

  • template_id, str_id, name, rarity, element, profession, weapon_type
  • level, potential_level (int)
  • splash_url, bg_url, round_icon_url (str)
  • main_attribute, sub_attribute (CharAttr): Primary/Secondary base attributes.
  • base_atk, base_hp (BaseAttr)
  • base_attribute (List[BaseAttr]): Full list of base attribute modifiers.
  • weapon (WeaponData): Information regarding the equipped weapon.
  • equips (List[EquipData]): Information regarding equipped relics/items.
  • suit_sets (SuitSet | null): Active relic suit set bonuses.
  • skills (SkillMeta): Character active skills.
  • talents (TalentInfo): Character talent trees and nodes.
  • stats (ComputedStats): Final computed statistical map.
  • detailed_stats (ComputedStatsWithDetails): Expanded view of stats with icons.
